🔥 90 Days Life Challenge Bot

A powerful Telegram bot built with Python to help users improve their lifestyle through a structured 90-day challenge.

This bot tracks daily habits, calculates scores, and generates reports to keep users accountable and motivated.

🎯 Features
🛌 Sleep tracking with automatic duration calculation and scoring
🚬 Cigarette tracking with daily limits and penalties
💧 Water intake tracking (with reminders - upcoming)
🍽 Calorie tracking per meal (planned)
📚 Study time tracking
🏃 Workout / walking tracking
📸 Daily photo logging (morning & night)
📝 Daily journaling
📊 Daily, weekly, and monthly reports (planned)
⚔️ Competitive mode between two users
🧠 Concept

The bot is designed around a 90-day transformation challenge, focusing on:

Consistency over perfection
Positive reinforcement + light penalties
Self-awareness through tracking
Motivation through competition

🚀 Getting Started
1. Clone the repo
git clone https://github.com/your-username/life-challenge-bot.git
cd life-challenge-bot
2. Install dependencies
pip install -r requirements.txt
3. Add your bot token

Edit config.py:

BOT_TOKEN = "YOUR_TOKEN"
4. Run the bot
python bot.py
